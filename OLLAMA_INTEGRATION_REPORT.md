# SHIELD-LLM — Ollama Protected LLM Gateway Integration Report

**Date:** October 20, 2026  
**System:** SHIELD-LLM Hybrid Prompt Injection Defense Gateway  
**Target LLM:** Local Ollama (`gemma3:1b`) with 100% GPU offload on NVIDIA GeForce GTX 1650 (4 GB VRAM)  
**Host & Local API Endpoint:** `http://127.0.0.1:11434`  
**Classifier in Use:** Phase 5D DistilBERT (`ml/models/distilbert_phase5d/`)  
**Semantic Reference Bank:** Phase 5G Sanitized Reference Bank (`data/train_phase5g.csv`, 2,000 reference attack embeddings)  
**Detection Architecture:** Unmodified 3-Tier FusionEngine (Rules Engine + Semantic Detector + DistilBERT Classifier)

---

## 1. Executive Summary

SHIELD-LLM has been upgraded from a prompt injection detection dashboard to an **end-to-end operational AI Security Gateway**. Incoming user prompts submitted from the React UI are intercepted server-side by the FastAPI backend before reaching any downstream language model.

1. **Security Isolation & Server-Side Enforcement:**
   - Prompts classified as **MALICIOUS** or **SUSPICIOUS** are immediately arrested at the gateway. The downstream Ollama API is **never invoked**, guaranteeing zero GPU cycles spent processing adversarial inputs and zero risk of prompt leakage, jailbreaking, or unauthorized instruction execution.
   - Only prompts with a verified **SAFE** verdict from the hybrid `FusionEngine` are forwarded to the local Ollama instance (`http://127.0.0.1:11434/api/chat`).
2. **Real Downstream Execution:**
   - Simulated responses have been completely eliminated. Real inferences generated by Google's `gemma3:1b` model running locally on the user's NVIDIA GTX 1650 GPU are captured and displayed in the UI.
3. **Graceful Fault Tolerance:**
   - If the Ollama service is stopped or unreachable, the gateway reports an informative error without producing fake or simulated answers.

### 2.2 Ollama API Protocol & Configuration

The provider adapter (`backend/llm_provider.py`) uses the official Ollama REST API:

- **Endpoint:** `POST http://127.0.0.1:11434/api/chat`
- **Request Payload:**
  ```json
  {
    "model": "gemma3:1b",
    "messages": [
      {
        "role": "system",
        "content": "You are a helpful, concise AI assistant operating behind the SHIELD-LLM security gateway."
      },
      {
        "role": "user",
        "content": "<user prompt>"
      }
    ],
    "stream": false,
    "options": {
      "num_predict": 256,
      "temperature": 0.7
    }
  }
  ```
- **Response Extraction:** Parses `response["message"]["content"]` and strips whitespace.
- **Environment Overrides (`.env`):**
  ```env
  LLM_PROVIDER=ollama
  OLLAMA_BASE_URL=http://127.0.0.1:11434
  OLLAMA_MODEL=gemma3:1b
  OLLAMA_TIMEOUT=25.0
  OLLAMA_MAX_TOKENS=256
  ```

## 5. UI Presentation & Gateway States

The frontend adapts its Downstream LLM Gateway card depending on the verdict:

### State A: SAFE Verdict
- **Badge:** `FORWARDED TO LOCAL LLM` (Emerald)
- **Status Line:** `Live Gemma Response Generated • Model: GEMMA3:1B (Ollama GPU)`
- **Content:** The actual unsimulated text response generated by Gemma running on the local GTX 1650.
- **Raw Engine Details:** Collapsible section displaying Classifier score (e.g. 0.004), Semantic score (e.g. 0.45), and Rules weight (0.0).

### State B: MALICIOUS Verdict
- **Badge:** `THREAT BLOCKED • NOT FORWARDED` (Rose)
- **Content:** "Threat Blocked: Security policy prohibited downstream generation. Prompt not forwarded to LLM."
- **Security Explanation:** Clearly itemizes matched attack categories (e.g. `instruction_override`, `prompt_extraction`) and states `"Prompt not forwarded to LLM."`

### State C: SUSPICIOUS Verdict
- **Badge:** `REVIEW REQUIRED • NOT FORWARDED` (Amber)
- **Content:** "Forwarding Suspended: Prompt exhibited elevated risk indicators. Prompt not forwarded to LLM pending review."

## 7. Remaining Considerations & Production Recommendations

1. **First-Inference Cold Start:**
   - On the very first prompt sent to Ollama after computer restart, Windows may take 2-4 seconds to page the 1-billion-parameter weights into GPU VRAM. Subsequent inferences respond in ~0.5 - 1.5 seconds.
2. **Context Window Configuration:**
   - The default `num_predict` is set to 256 tokens, which is optimal for rapid interactive security demonstrations on a 4 GB GTX 1650. For longer outputs, adjust `OLLAMA_MAX_TOKENS` in `.env`.
3. **ML Architecture Preservation:**
   - No model weights were modified, no retraining was performed, and all detection thresholds remain identical to Phase 5D / Phase 5G specifications.
